# html-doc-style

一套用于生成**中文长文 HTML** 的版式规范，以 WorkBuddy 用户级 Skill 的形式提供。

它把「暖白纸底 + 墨绿主色」的文档设计系统固化成硬约束：所有颜色与字体收在 `:root` 变量里，字号、间距、圆角各自只用一小把离散刻度，引用统一走四种语义提示块，命令行是全页唯一的深色反相区块。产物是**单文件、离线可看、可直接打印成 PDF** 的 HTML。

适用：教程、指南、技术手册、复盘、报告、说明书、速查页。
不适用：对话内联 SVG 卡片图、把 HTML 转成 `.pdf` 文件、完整网站或应用 UI 设计。

## 快速开始

### 安装

把本仓库整个目录放到 WorkBuddy 的用户级技能目录：

```
~/.workbuddy/skills/html-doc-style/
```

Windows 对应 `%USERPROFILE%\.workbuddy\skills\html-doc-style\`。也可以把仓库打包成 zip，用技能安装入口导入。

安装完成后，在对话里直接说「把这份内容写成 HTML 教程」「按版式规范生成一份报告」即可自动套用；也可显式指定 `用 html-doc-style`。新装或更新后建议重开一个会话，让技能索引刷新。

### 生成文档

技能会在生成前读取两份参考文档，然后把 `assets/doc-style.css` 原样内联进 `<style>`，产出单个 `.html`：

```bash
python scripts/validate_html.py 输出文件.html
```

校验脚本是纯 Python 标准库实现，检查 DOCTYPE / charset / viewport、样式表关键规则、目录锚点与 `<section id>` 对应、标签闭合、`pre` 是否包在 `.codewrap` 里、外部 CDN 资源、命令反斜杠续行、字阶越界、底部脚本缺失等。加 `--strict` 可把 WARN 也当作失败。

如果明确要多页共用一份样式，才改用 `<link rel="stylesheet" href="doc-style.css">`，且 CSS 必须与 HTML 同级。

| 路径 | 内容 |

## 规范摘要

- **字体两族**：系统无衬线栈（中文自动落雅黑 / 苹方，不加载外部字体）+ 等宽栈（只给代码、编号、数字）。
- **字阶 12 个固定值**：主档 `32 / 21 / 15 / 14.5 / 13.5 / 12.5 / 11.5`，组件辅助 `14 / 13 / 12 / 11 / 10.5`；字重 `400 / 600 / 650 / 700`。正文行高 **1.85**，正文列约 890px。
- **配色**：主色 `#0d8060` + 琥珀（注意）+ 砖红（危险），每个强色配同色相 soft 浅底；文字四级灰阶建立层级；强色面积压在 5% 以内。
- **引用**：不用 `<blockquote>`，统一 `.callout` 四态 `note / ok / warn / danger`，带标题与语义色。
- **表格**：无竖线、仅横向分隔线、表头浅米底、数字列等宽。
- **命令行**：全页唯一深色反相区块 `#121a24`，语法只上三色，右上角一键复制；命令必须给一整行，不用反斜杠续行（PowerShell 不认）。
- **布局**：1200px 容器 = 216px sticky 目录 + 52px 沟槽 + 正文列；920px 断点折叠；`@media print` 隐藏目录与按钮、把深色代码块反相为浅底、禁止表格跨页截断。

换配色只需改 `:root` 里的 `--accent` 与 `--accent-soft` 一对值，引用它的所有页面会一起变。完整取值与禁止项见 `references/design-system.md`。
