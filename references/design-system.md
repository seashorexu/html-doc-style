# 文档版式设计系统（完整规范）

本文件是 `html-doc-style` 技能的权威规范。生成或修改 HTML 文档时，所有视觉取值以此为准。
来源：2026-11-10 交付的 `教程_从升级llama.cpp到提示词工作流.html`，其内联样式被逐条提取为 `assets/doc-style.css`，数值未改。

---

## 1. 设计变量（`:root`）

所有颜色、字体集中在 `:root`；页面正文中**不得出现散落的十六进制色值**（色板演示等展示用途除外）。

```css
:root{
  /* 纸底与卡片 */
  --paper:#fbfaf7; --card:#ffffff;
  /* 文字四级灰阶：正文 → 次要 → 弱化 → 极弱 */
  --ink:#1c2530; --muted:#5d6a7a; --dim:#8a95a2;
  /* 描边两级 */
  --line:#e4e1d9; --line2:#efece4;
  /* 主色 + 语义色（每个强色都有同色相 soft 版） */
  --accent:#0d8060; --accent-soft:#e8f5ef;
  --amber:#a9701a;  --amber-soft:#fdf3e2;
  --danger:#b84a3d; --danger-soft:#fdf0ee;
  /* 代码块（唯一深色反相） */
  --code-bg:#121a24; --code-fg:#dce6f0;
  /* 字体栈 */
  --sans:-apple-system,BlinkMacSystemFont,"Segoe UI","Microsoft YaHei","PingFang SC",sans-serif;
  --mono:"Cascadia Code",Consolas,"SF Mono",Menlo,monospace;
}
```

| 变量 | 色值 | 角色 |
|---|---|---|
| `--paper` | `#fbfaf7` | 页面背景，暖白不刺眼 |
| `--card` | `#ffffff` | 卡片 / 表格底，比纸底亮一档 |
| `--ink` | `#1c2530` | 正文，深蓝灰，**不用纯黑** |
| `--muted` | `#5d6a7a` | 导语、表头、卡片说明 |
| `--dim` | `#8a95a2` | 目录编号、页脚、极弱元信息 |
| `--line` | `#e4e1d9` | 统一 1px 描边 |
| `--line2` | `#efece4` | 表格内横向分隔线 |
| `--accent` | `#0d8060` | 墨绿主色 |
| `--accent-soft` | `#e8f5ef` | 主色浅底，同色相 |
| `--amber` / `--amber-soft` | `#a9701a` / `#fdf3e2` | 注意 / 注意浅底 |
| `--danger` / `--danger-soft` | `#b84a3d` / `#fdf0ee` | 危险 / 危险浅底 |
| `--code-bg` / `--code-fg` | `#121a24` / `#dce6f0` | 代码块，全页唯一深色反相 |

补充固定色（不属于变量，但同样是规范的一部分）：

| 用途 | 值 |
|---|---|
| 行内代码底 / 字 | `#f0eee7` / `#8a4a12` |
| 表头底 | `#f5f3ed` |
| 表格 hover 底 | `#faf9f5` |
| note 提示块 | 底 `#f1f5f9`、边 `#dbe3ec`、字 `#31465c`、标题 `#2a5b86` |
| warn 提示块边 | `#efd9ae`，字 `#6b4a14` |
| danger 提示块边 | `#f0cfc9`，字 `#7d3a31` |
| ok 提示块边 | `#c3e6d7`，字 `#155c47` |
| 第三种徽标 | 底 `#eef1f6`，字 `#4a5a70` |
| 代码语法三色 | `.cmt #7e93a8` / `.key #7fd4b0` / `.str #e6c07b` |

## 2. 配色规则

1. **色相做减法**：全页只有一个主色（墨绿）+ 两个语义色（琥珀=注意、砖红=危险），其余全是灰阶。禁止引入第四个互不相干的色相。
2. **强色面积 < 5%**：墨绿只用于章节编号 `.idx`、链接、目录当前项、状态词、步骤序号。大面积一律用 soft 版或灰阶。
3. **强色成对**：每个强色都配同色相的 soft 底色，用于徽标 / 提示块背景。不要另调一个新颜色。
4. **层级靠灰阶**：正文 / 次要 / 弱化 / 极弱四级分工明确；标题才用字重区分。不靠「把文字加粗或改字号」制造层级。
5. **唯一反相**：只有 `pre` 用深色底。卡片、表格、提示块一律浅底 + 1px 边框，代码块因此天然成为视觉焦点。
6. **氛围极轻**：`body::before` 用 7% / 6% 透明度的双色径向渐变做页首光晕，`pointer-events:none`，不参与内容层级。

## 3. 字体与字阶

**两族字体，各司其职**：`--sans` 系统无衬线栈（中文自动落到雅黑 / 苹方，不加载任何外部字体）；`--mono` 等宽栈，只用于代码、编号、数字列。

字号采用 **7 个主档 + 5 个组件辅助档**（共 12 个固定值），字重 **4 档**（400 / 600 / 650 / 700）：

| 档位 | 字号 | 字重 | 用途 |
|---|---|---|---|
| `h1` | 32px | 700 | 仅页首一次；行高 1.35、字距 −0.4px |
| `h2` | 21px | 700 | 每章一次；配 `.idx` 编号徽标 |
| `.lead` | 15px | 400 | 页首摘要，限宽 760px |
| `h3` | 15px | 650 | 章内分节，上留白 28px |
| 正文 | 14.5px | 400 | **行高 1.85**，中文长文舒适的关键值 |
| `h4` / `.sec-lead` | 13.5px | 650 / 400 | 次级说明，用 `--muted` |
| 表格 / 卡片 / 目录 / 提示 / 代码 | 12.5px | 400 | 组件文字，行高约 1.7 |
| 徽标 / 表头 / 胶囊 / 页脚 / kicker | 11.5px | 650–700 | 元信息 |
| 组件辅助档 | 14 / 13 / 12 / 11 / 10.5px | 400–700 | 卡片标题 14、提示块 13、代码块与编号 12、步骤点 11、徽标与目录眉题 10.5；均为规范内固定值 |

其余细节：
- `pre` 12px、行高 1.75；目录 12.5px、行高 1.5；提示块 13px、行高 1.75。
- `code` 行内取父级 `0.88em`，`white-space:nowrap`；表格内的 `code` 改为 `white-space:normal; word-break:break-word`。
- `strong` 统一 650，不用 700 或 bold。
- 全页 `-webkit-font-smoothing:antialiased`。

## 4. 间距 / 圆角 / 描边刻度

所有空白取自同一小把数字，**禁止出现 13px、17px 这类「差不多」的值**。

- 间距刻度（px）：`4 / 8 / 12 / 16 / 20 / 28 / 34 / 52`
- 圆角刻度（px）：`4 / 6 / 8 / 10 / 12 / 99`

| 对象 | 数值 |
|---|---|
| 章节之间 | 52px（全页最大呼吸，靠留白而非分割线分章） |
| 页首内边距 | 52 / 40 / 34（上 / 左右 / 下） |
| 卡片内边距 | 18 × 20 |
| 表格单元 | 10 × 12 |
| 代码块内边距 | 16 × 18 |
| 标题与正文 | 6–12（紧贴）；`h3` 上留 28px |
| 组件之间 | 14–18 |
| 圆角分配 | 行内码 4 → 徽标 5/6 → 步骤点 8 → 提示/表格/代码 10 → 卡片 12 → 胶囊 99（**元素越大圆角越大**） |
| 描边 | 统一 1px `var(--line)`；hover 只改一个色阶，**不叠阴影、不加粗边框** |
| 过渡 | `transition:.15s` |

## 5. 布局与响应式

| 参数 | 值 | 原因 |
|---|---|---|
| 容器最大宽 | 1200px | 宽屏不拉满，两侧留白；内部 40px 内边距 |
| 目录列 | 216px，`position:sticky; top:24px` | 滚动时始终可见，当前章高亮 |
| 沟槽 | 52px | 目录与正文彻底分开，不需要竖线 |
| 正文列 | ≈ 890px | 中文约 45–55 字 / 行 |
| 页首摘要限宽 | 760px | 视线更容易进入 |
| 栅格 | `grid-template-columns:216px minmax(0,1fr)`，`gap:52px`，`align-items:start` | `main{min-width:0}` 防溢出 |

`920px` 断点：
- `.layout` 改单列、`gap:0`、左右 22px；
- `.toc` 改 `position:static`、横排 flex 胶囊，链接加 1px 边框；
- `.cards` 改单列；`.hero` 内边距缩小；`h1` 降到 25px。

`html{scroll-behavior:smooth}`、`section{scroll-margin-top:24px}`。

## 6. 打印规则（必须有）

```css
@media print{
  body{background:#fff; font-size:11pt}
  body::before,.toc,.copy,footer{display:none}
  .layout{display:block; padding:0; max-width:none}
  .hero{padding:0 0 18px}
  h1{font-size:22pt}
  section{break-inside:auto; margin-bottom:26px}
  h2,h3{break-after:avoid}
  pre,table,.callout,.card{break-inside:avoid}
  pre{background:#f4f4f2; color:#222; border:1px solid #ddd}
  .cmt{color:#6a7a88}.key{color:#0a6b50}.str{color:#8a5a10}
  a{color:inherit; text-decoration:none}
}
```

要点：隐藏目录 / 光晕 / 复制按钮 / 页脚；**深色代码块反相为浅底省墨**；标题禁止孤行；表格、提示块、代码块禁止跨页切断；链接去色去下划线。这样「打印 → 另存为 PDF」直接可用。

## 7. 让页面「舒服」的七条原则

1. **颜色先做减法**——一个主色 + 两个语义色，强色面积 < 5%。
2. **层级靠灰阶，不靠加粗**——四级文字灰阶分担不同信息角色。
3. **取值离散化**——字号 12 个固定值、间距 8 个值、圆角 6 个值，所有元素从表里挑。
4. **浅底 + 1px 描边统一所有区块**，只有代码块反相形成唯一焦点。
5. **正文行高与行宽一起管**——中文 1.85、正文列 ≤ 890px。
6. **结构重复**——每章都是「编号 + 标题 + 一句导语」，表格都是「表头 + 无竖线」。
7. **交互做轻**——hover 只变一个色阶，0.15s，无阴影堆叠。

核心方法论：**先定义系统，再写页面**。先把 `:root`、字阶表、间距刻度、组件清单定死，内容只是往格子里填；边写边调样式几乎必然出现漂移。

## 8. 常见漂移与禁止项

| 禁止 | 原因 / 替代 |
|---|---|
| 正文里写死 `#333`、`font-size:17px` | 破坏一致性；改用变量与固定字阶 |
| 用纯黑 `#000` 做正文或页面底 | 与暖白纸底冲突；用 `--ink` / `--paper` |
| 引入第四个强调色 | 用现有 soft 版或灰阶 |
| 给卡片加 box-shadow | 统一用 1px 描边 |
| 表格加竖线、加斑马纹 | 只允许横向 `--line2` 分隔与 hover 微变色 |
| 用 `<blockquote>` 做引用 | 统一用 `.callout` 四态（结构见 `components.md`） |
| 代码块里做完整语法高亮 | 只用 `.cmt` / `.key` / `.str` 三色 |
| Windows 命令用 `\` 分行续行 | PowerShell 不认；给一整行可复制文本，宁可横向滚动 |
| 加载 Google Fonts / CDN / 外部图片 | 破坏离线；用系统字体栈 |
| 漏写 `@media print` | 代码块打印会糊成黑块 |

## 9. 可选进阶：尺寸变量化

原稿把**颜色与字体**变量化了，但**字号与间距**是写死的离散数值。为 100% 复刻效果，`assets/doc-style.css` 保持原样未改。若项目需要一键缩放整套版式，可在 `:root` 补充并替换引用：

```css
--fs-h1:32px; --fs-h2:21px; --fs-h3:15px; --fs-body:14.5px;
--fs-sub:13.5px; --fs-comp:12.5px; --fs-xs:11.5px;
--sp-1:4px; --sp-2:8px; --sp-3:12px; --sp-4:16px;
--sp-5:20px; --sp-6:28px; --sp-7:34px; --sp-8:52px;
```

## 10. 换主题

替换 `--accent` 与 `--accent-soft` 为品牌色（一深一浅、同色相），引用该样式表的全部页面会一起变。**不要去改页面里的颜色**。若换的是深色主题，需同步调整 `--paper` / `--card` / 四级文字灰阶 / `--code-bg`，并检查 `@media print` 的反相规则。
