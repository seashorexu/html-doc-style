00一页速查

先分层，让读者一眼分清「不用重做 / 每次要做 / 日常循环」。

A · 一次性

卡片标题

说明文字 12.5px，次要灰。三列并排适合并列概念；如果只有一段内容，去掉 .cards 直接用单个 .card。

B · 每次

卡片标题

徽标 .badge / .badge.b / .badge.c 对应三种主次配色，顺序固定。

C · 日常

卡片标题

内容里可以放 行内代码，暖灰底棕字，和深色代码块区分开。

结论 / 记住这一行就够

把最希望读者记住的一句话放这里。四态：note 中性说明、ok 结论、warn 注意、danger 危险。

01正文与代码

每章都用「编号 + 标题 + 一句导语」开头，结构重复产生秩序感。

1.1　节标题

正文 14.5px、行高 1.85。中文长文不要压行距。需要强调的用 650 字重，不要改字号；提到文件名、参数、命令用 行内代码。

  • 列表项之间留 5px，整体下留 14px。
  • 术语保持准确，例如 start_after_reboot.cmd 不要写成别的名字。

1.2　代码示例

整段命令用 .codewrap > pre，右上角复制按钮由页面底部脚本自动注入。命令写成一整行，不要用反斜杠续行（PowerShell 不认）。

# 注释用 .cmt（灰蓝）
llama serve -m "model.gguf" -ngl 99 -c 8192 -np 1
注意 / 容易踩的坑

需要留意但不至于失败的边界条件放这里；会丢数据的用 .callout.danger。

02表格与流程

表格无竖线、只有横向分隔线；数字列加 .num 用等宽字。

项目数值说明
示例项8192说明文字，可放 行内代码；状态用 正常 / 异常
示例项12.5px表格文字统一 12.5px，表头 11.5px
示例项—最后一行自动去掉底线

2.1　操作步骤

  1. 第一步

    序号由 CSS 计数器自动生成，不用手写数字。

  2. 第二步

    竖线自动串联，最后一项自动去掉。

  3. 第三步

    标题 14px 深色，说明 12.5px 次要灰。
